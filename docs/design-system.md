# IHL Design System

Figma: Mockups (Internal). Page Design System holds the foundation docs: Colours, Typography, Spacing, Layout, Icons, Illustrations, App icon, Screens · Events. Page Components holds the app kit docs. Pages Mockups V1 and Mockups V2 hold the core flows for client review, without and with the seeker round. Colors live in docs/colour-tokens.md.

Doc layout follows the reference template: dark header bar, page title with the IHL logo, then each section as a label with a #F5F5F3 panel. Doc text is Inter: labels 20 Semi Bold, titles 16/26 Bold, body 16/26 Regular. Component docs follow the Form Fields reference: Base component, Anatomy, Variants, Examples (Light and Dark), Do and don't.

## Principles

- Keep text in the app to a minimum, focus on the experience and let whitespace carry the layout
- One job per screen, labeled and visible controls, few filters up front, gentle forms, undo over confirm dialogs
- Glass is a rare accent: tab bar, buttons on photos, the welcome sheet

## Typography

- Manrope for every word in the app. Mrs Saint Delafield as a decorative accent, one word per screen, never for dates, prices or buttons
- Two weights only: Medium 500 for reading and Bold 700 for emphasis. Medium replaced Regular 400 in September 2026
- Text styles, each in Medium and Bold, bound to the Typography collection (23 variables, font/weight/medium and font/weight/bold)
  - Heading/H1 34/41 (iOS Large Title), H2 28/34 (Title 1), H3 22/28 (Title 2), H4 20/25 (Title 3), H5 17/22 (Headline), H6 15/20 (Subhead)
  - Body/L 19/28 (iOS Body at xLarge), Body/M 17/26 (iOS Body), Body/S 15/22 (iOS Subhead)
  - Caption 13/18 (iOS Footnote)
- Letter spacing: tight -0.4 for H1 and H2, snug -0.2 for H3, normal 0 elsewhere
- Sizes match Apple HIG defaults. Body leading is looser for older readers. Floor is 13pt, above Apple's 11pt minimum
- Keep Dynamic Type on (allowFontScaling). Cap only a heading that breaks a layout, with maxFontSizeMultiplier
- Code: Manrope_500Medium and Manrope_700Bold from @expo-google-fonts/manrope

## Spacing

- Nine tokens named by their value in points: spacing/4, 8, 12, 16, 20, 24, 40, 48, 64, scoped to gap and padding. Code uses the same numbers: spacing[20] is 20. Component sizes off the scale (56pt button, 52 by 32 toggle) live in the component
- Touch targets 48pt minimum (spacing/48). Primary buttons 56pt (spacing/56). 8pt between neighboring targets
- Screen side margin is 16pt (spacing/16). Content width is 370pt at 402. Grid styles use a 16pt margin and 16pt gutter
- Hierarchy on tab screens: 12pt inside a group (search and filters, a label and its list), 20pt between groups (set by Steven, applied to every Home, Directory and Community screen)
- Light canvas is sand/10 #F4F0E8, a beige white (October 2, 2026), so white cards still separate from it. bg/color-surface is sand/20 for skeletons and disabled fills. Sheets were sand/5 with white fields until October 5, 2026, when Steven asked for no white over beige: a sheet is now the canvas beige sand/10, and what sits on it uses sand/20
- October 12, 2026: the Light canvas and sheets move to #F8F4EE, a step lighter than sand/10, picked from six options in the review panel. The app icon keeps sand/10

## Radius

- Named by value like spacing: radius/4, 8, 12, 16, 20, 24, 40 and radius/full (999). Square corners are plain 0
- 8 for checkboxes and small controls, 12 for thumbnails, 16 for banners, grouped lists and the message box, 20 for cards and photos, 24 for the bottom curve of a full-bleed hero photo, 40 for the top corners of a bottom sheet and the device corner on mockup frames, full for buttons, chips, the tab bar and avatars

## Icons

- Iconoir replaced Hugeicons in September 2026. MIT licensed, free in Regular and Solid
- Published library: the trimmed Iconoir file in the Mockups (Internal) folder, Regular and Solid only, glyphs black at the source. In Mockups every icon sits in a slot whose Color layer is bound to an icon token, so a swapped icon keeps its color and flips with the mode
- iconoir 7.12.1 has 1,383 Regular and 288 Solid icons on a 24pt grid with a 1.5 stroke
- React Native: iconoir-react-native 7.12.1, MIT, no dependencies, npm audit 0 vulnerabilities (September 2026). Import from iconoir-react-native/regular and iconoir-react-native/solid. Needs react-native 0.78 or newer and react-native-svg 15.12 or newer
- Keep both MIT notices in the app's acknowledgements: Iconoir icons, Copyright (c) 2021 Luca Burgio. iconoir-react-native, Copyright (c) 2021 Daniel Martin, Pascal Jufer
- Solid covers part of the set only. Home, group, search and user-circle have no Solid, so selected tabs keep the tinted pill and bold label. Solid exists for bookmark, heart, check-circle, warning-triangle, warning-circle, info-circle, clock, chat-bubble, star and others
- Sizes 20, 24 (default), 28 (tab bar), 48 (feature circles)
- The Icons doc lists the icons in use: map for the Directory tab, menu for the Community topics and Directory categories buttons, open-new-window in Get directions, maps-arrow-diagonal on the Directions pill. The old Hugeicons components are gone, and Screens · Events now uses Iconoir
